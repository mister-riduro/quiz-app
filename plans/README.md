## Plan Summaries

### [001: Fix Audio Memory Leak and Sound Clash](001-fix-audio-memory-leak-and-sound-clash.md)

- **Problem:** Unbounded Web Audio node accumulation in `SoundManager`, clashing double audio triggers on question evaluation, and over-subscription re-renders across all leaf components when mute is clicked.
- **Fix:** Maintain a singleton `masterGainNode` with explicit `osc.onended` disconnection, split `useSound` (action-only) from `useSoundSettings` (stateful), and remove clashing evaluation audio listeners from player components.

### [002: Prevent Question State Leak and Render Waste](002-prevent-question-state-leak-and-render-waste.md)

- **Problem:** Missing `key={activeQuestion.id}` in `PresenterKioskPage.tsx` causes component state to leak when moving between questions of the same type; hot-path keystrokes re-render all question items in `QuizBuilderPage`; duplicate store `useQuizBuilderStore` remains in the tree; unhandled `onAuthStateChange` listener in `authStore`.
- **Fix:** Bind `key={activeQuestion.id}` inside `AnimatePresence mode="wait"`, wrap `SortableQuestionItem` and `WordsearchCell` in `React.memo`, deprecate `useQuizBuilderStore`, and properly unsubscribe `supabase.auth` listeners.

### [003: Eliminate Design Token Drift and Unify 3D Bevels](003-eliminate-design-token-drift-and-unify-3d-bevels.md)

- **Problem:** Over 120+ occurrences of hardcoded hex values outside `duo-*` tokens; missing top/left borders (`border-2`) in `TactileButton`; broken active press (`active:border-b-0`) flattening bevels in `BottomSheetFeedback` and `VictoryScreen`; inconsistent rounded corner hierarchy.
- **Fix:** Add `duo-muted` token, supply missing `border-2` in `TactileButton`, standardize active compression (`active:translate-y-[2px] active:border-b-2`), replace inline buttons with `TactileButton`, enforce a 3-tier rounded corner system, and delete dead `DuoBottomSheet.tsx`.

### [004: Enforce 44x44px Touch Targets and Zero Click Delay](004-enforce-touch-targets-and-zero-click-delay.md)

- **Problem:** Sub-44px touch targets in `TactileButton size="sm"` (~32px), `CrosswordPlayer` (36px cells, 28x40px keys), `HangmanPlayer` (32px keys), and kiosk controls (36-40px); missing `touch-action: manipulation` causes 300ms double-tap delay on iPads and Android tablets.
- **Fix:** Add global `touch-action: manipulation` in `index.css`, enforce minimum 44px height across all `TactileButton` variants, resize header/kiosk icon controls to `w-11 h-11` (44px), and enlarge virtual keyboards for classroom touchscreens.

### [005: Refine Framer Motion Physics and Transitions](005-refine-framer-motion-physics-and-transitions.md)

- **Problem:** `scale: 0` in `Star3D` triggers matrix singular layout glitches; bottom sheet combines opacity fade with vertical spring creating a muddy wash-out; linear array keyframes in `TileToken` shake feel robotic; `transition-all` causes layout recalculations.
- **Fix:** Change initial scale to `scale: 0.15`, remove opacity fade from bottom sheet spring, implement damped spring shake on `TileToken`, and replace `transition-all` with targeted compositor-only transitions (`transform`, `box-shadow`, `background-color`).
